# Canva Setup Guide — Oro Adventure Tours

## Quick Setup Checklist

### Step 1: Create a Canva Brand Kit
1. Go to [canva.com](https://canva.com) → click **"Brand Hub"** (requires Canva Pro) or use free manual setup
2. Set your **Brand Colors** using these hex codes:
   - `#D4981F` — Adventure Gold (Primary)
   - `#1A8A7B` — Ocean Teal (Secondary)
   - `#2D7D46` — Mangrove Green (Accent)
   - `#0D2B45` — Deep Navy (Dark Base)
   - `#FFF8EC` — Cream White (Light)
3. Upload your **Oro Adventure Tours logo** to the Brand Kit
4. Set **Brand Fonts:**
   - Heading: Playfair Display
   - Subheading: Raleway
   - Body: Open Sans

## Canva Quick Tips

- **Batch create** all 10 posts in one Canva project folder — name it "Oro Adventure Tours — Campaign 1"
- **Lock branding elements** (logo, color bar) so they stay consistent across resizes
- Use **Canva's Magic Resize** to instantly adapt square posts to story format
- **Download settings:** PNG for photos, PNG transparent for logo overlays
- Use **Canva Scheduler** (free tier allows some scheduling) to publish directly to Facebook and Instagram
